# Especificações (specs/)

## Formato

Cada spec deve seguir este estrutura:

```markdown
# Nome da Feature

## 1. Requisito Confirmado
Breve descrição do problema/necessidade.

---

## 2. Abordagem
Explicação da solução técnica recomendada.
Inclua diagramas se necessário.

---

## 3. Detalhes Técnicos
- Biblioteca/tool recomendada
- Alternativas consideradas
- Trade-offs

---

## 4. Tasks de Implementação

### Fase 1: Nome
- [ ] Task 1
- [ ] Task 2

### Fase 2: Nome
- [ ] Task 3

---

## 5. Referências
- Link 1
- Link 2
```

## Regras

- **Idioma**: Português para tudo (títulos, texto, código)
- **Título**: `NomeDaFeature.md` (PascalCase)
- **Intenção**: Documentar decisão antes de implementar
- **Manter conciso**: Máximo 100 linhas por spec
